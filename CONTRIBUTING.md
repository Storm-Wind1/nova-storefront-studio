# Contributing to NOVA Store

Thanks for your interest in helping improve this fictional e-commerce frontend demo.

## Ways to help

- Report reproducible bugs or accessibility issues.
- Improve React/TypeScript code, validation, state management, and automated tests.
- Improve developer documentation and cross-browser behavior.

## Before opening a pull request

1. Check existing issues and pull requests to avoid duplicates.
2. Fork the repository or work on a branch.
3. Make a focused change and explain why it is needed.
4. Run the checks:
   ```sh
   npm ci
   npm run typecheck
   npm test
   npm run lint
   npm run build:pages
   ```
5. Open a pull request describing the change, tests, and screenshots if it affects the UI.

Please do not include credentials, private data, unauthorized assets, or breaking behavior without documenting the impact.
